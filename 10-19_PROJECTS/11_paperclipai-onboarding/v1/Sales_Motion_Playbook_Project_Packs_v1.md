# KG Services Sales & Motion Playbook
## For Digital Project Packs via Systeme.io

### Overview
This playbook outlines the marketing-led sales motion for selling digital project packs/bundles via Systeme.io.
We do NOT use inside sales, ABM, or partner channels (yet).

### Funnel Architecture
1. **Traffic Sources**:
   - Blog posts (SEO-driven)
   - Social media (LinkedIn, Facebook, Instagram)
   - Guest posts on industry blogs
   - Pinterest (for visual project templates)
   - Referral partnerships (future)

2. **Lead Magnets**:
   - Free sample project pack (e.g., "Business Plan Starter Kit")
   - Checklist templates
   - Mini-guides related to project types

3. **Landing Pages** (Systeme.io):
   - Dedicated landing page per project pack or bundle
   - Clear value proposition: "Save weeks of document creation"
   - Social proof (testimonials, case studies)
   - Strong CTA: "Download Now" or "Get Instant Access"

4. **Email Sequences** (Systeme.io Automation):
   - Welcome sequence (deliver lead magnet, nurture)
   - Educational sequence (teach about project type, show need)
   - Promotion sequence (highlight specific pack, limited-time offer)
   - Post-purchase sequence (onboarding, upsell, review request)

5. **Course Delivery** (Systeme.io):
   - After purchase, customer gets access to course module
   - Includes: ZIP download link, video lessons (MP4), usage guide
   - Progress tracking (optional)

### Sales Process (Self-Serve)
- No sales calls required
- Customer journey: Discover → Learn → Trust → Buy → Use → Refer
- Average sales cycle: Minutes to hours (impulse buy based on need)

### Pricing & Packaging
- **Individual Packs**: $29-$99 (one-time)
  - Best for: Specific project need
- **Bundles/Phases**: $199-$499
  - Best for: Multiple related projects (e.g., "Startup Founder Bundle")
- **Full Catalog**: $997-$1,997 (lifetime or annual)
  - Best for: Agencies, consultants, frequent users

### Conversion Optimization Tactics
1. **Scarcity**: Limited-time discount bundles
2. **Social Proof**: Video testimonials, case study PDFs
3. **Risk Reversal**: 30-day money-back guarantee (if applicable)
4. **Upsells**: 
   - Order bump: "Add video tutorial for +$15"
   - Post-purchase: "Complete the bundle and save 20%"
5. **Cross-sells**: "Customers who bought this also bought..."

### Traffic & Content Strategy
- **Blog**: 2-3 posts per week targeting project-type keywords
  - Example: "How to Run a Non-Profit Fundraiser in 30 Days"
  - Each post content upgrades to relevant project pack
- **Social Media**:
  - LinkedIn: Professional templates (consultants, agencies)
  - Facebook: Small business, entrepreneurship groups
  - Instagram/Pinterest: Visual templates (event planning, design)
- **Lead Magnet Promotion**:
  - Content upgrades in blog posts
  - Social media posts driving to free offer
  - SEO for "free [project type] template"

### Metrics to Track
- **Funnel Metrics**:
  - Landing page conversion rate (visitor → lead)
  - Lead-to-customer rate (email sequence)
  - Average order value
  - Revenue per visitor
- **Email Metrics**:
  - Open rate, click-through rate
  - Conversion rate per email
- **Content Metrics**:
  - Blog traffic, time on page
  - Lead magnet download rate
- **Financial Metrics**:
  - Customer acquisition cost (CAC) - target <$20
  - Lifetime value (LTV) - though mostly one-time, track upsells
  - Refund rate (<5%)

### Team Responsibilities
- **Content Creator**: Write blog posts, create lead magnets, outline project packs
- **Designer**: Format documents, create visual assets, design landing pages
- **Marketer**: Set up Systeme.io funnels, run email sequences, manage social
- **Customer Support**: Handle email inquiries, maintain knowledge base

### Tools & Resources
- Primary: Systeme.io (all-in-one)
- Secondary: 
  - Notion (knowledge base, internal docs)
  - Canva/Adobe (design)
  - Google Workspace (document creation)
  - Audio/video tools (for lesson creation)
