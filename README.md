# KG Services Workspace

Shared document workspace for Paperclip AI and Hermes agent.
Organized with PARA + Johnny Decimal.

## Structure

- `00-09_SYSTEM` — conventions, templates, metadata
- `10-19_PROJECTS` — finite work with an end date
- `20-29_AREAS` — ongoing responsibilities
- `30-39_RESOURCES` — reference material
- `40-49_ARCHIVE` — completed or superseded
- `50-59_AGENTS` — agent scratch and outputs

See `00-09_SYSTEM/03_CONVENTIONS/README.md` for naming rules.
