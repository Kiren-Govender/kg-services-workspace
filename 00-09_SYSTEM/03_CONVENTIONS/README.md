# Naming Conventions

## Johnny Decimal
- Top level: `NN-NN_NAME` (e.g., `20-29_AREAS`)
- Second level: `NN_name` (e.g., `24_Marketing-Sales`)
- Files: `NN_description.md` (e.g., `24.01_q4-campaign.md`)

## Rules
- Numbers are never reused.
- Folders end in `_`, files end in `.md` or `.txt`.
- Dates in filenames: `YYYY-MM-DD` only.
- No spaces in filenames — use hyphens.

## Agent ownership
- Paperclip writes to `50-59_AGENTS/51_Paperclip/`
- Hermes writes to `50-59_AGENTS/52_Hermes/`
- Shared coordination: `50-59_AGENTS/53_Shared/`
- Deliverables go into the matching `1x/2x` folder, not the agent folder.
